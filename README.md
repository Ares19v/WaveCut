## ✨ Features

| Feature | Details |
|---------|---------|
| 🌌 **4D Tesseract Theme** | Interstellar-inspired cosmic interface with ambient perspective rays and deep void aesthetics |
| 🖼 **Dual Studio Mode** | Chrono Video Timeline Editor and Photon Image Studio |
| 🎬 **Multi-Track Timeline** | Video, Text/Overlay, and Audio tracks with precision playhead and timecode HUD |
| 🔊 **Procedural Web Audio** | Built-in soundscape synthesizer (Gargantua Deep Drone, Singularity Sweep, Quantum Pulsar) |
| ✂️ **Frame-Accurate Splitting** | Cut and slice clips at any playhead frame position (`S` key) |
| 🎨 **Prism FX Optics** | 1-click color grading presets (Tesseract Singularity, Deep Quantum Cyan, Prism Spectrum, Event Horizon Noir) |
| 📝 **Holographic Typography** | Styled text overlay layers with glow, shadow, and multi-font support |
| 🔲 **Non-Destructive Crop** | Smooth bounding box crop tool via Cropper.js |
| 📸 **Instant Snapshot** | 1-click high-resolution frame rasterizer and downloader |
| 📤 **Client-Side Master Export** | High-res PNG/JPEG/WebP images and 60fps WebM video recording with live progress feedback |
| 🔒 **100% Client-Side Privacy** | Media never leaves the browser; zero server processing |

## 🚀 Quick Start

### Installation & Run

```bash
npm install
npm run dev
```

Open **http://localhost:5173** (or the port indicated in the terminal).

### Build for Production

```bash
npm run build
```

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play / Pause Playback |
| `S` | Split Clip at Playhead |
| `Del` / `Backspace` | Delete Selected Layer |
| `V` | Transform / Select Tool |
| `C` | Crop Tool |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
